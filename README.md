# IBRT_CCE — Ibert Computational Civil Engineering

**Parametric, open, AI-assisted FEM platform for civil engineers.**
Status: pre-alpha (Phase 0 of 8). German project documents live in `docs/`.

IBRT_CCE brings the *Computational Engineering* paradigm (engineering
knowledge as executable code, designs generated by algorithms and checked
by physics) to structural engineering. Models are parameter graphs: change
a span, and the structure re-analyzes and re-optimizes itself. A visual
node editor, a game-like scene renderer and an LLM layer that translates
natural language into parameter graphs are on the roadmap — the mechanics
kernel always does the actual computing.

## What works today

A solver-agnostic core model (SI units, IFC-mappable entities) plus a
[Pynite](https://github.com/JWock82/Pynite)-based frame/truss adapter,
verified by an automated mechanics truth suite (`tests/benchmarks`,
cases B-001…B-005) against closed-form analytic solutions. Current
agreement is at machine precision (relative errors ≤ 2e-16). Results
without a passing benchmark do not officially exist in this project — see
`docs/VALIDATION.md`.

## Getting started

```bash
pip install -e ".[dev]"
pytest            # runs unit tests + mechanics benchmarks
```

Contributions (human or AI) follow `CLAUDE.md` (working rules),
`docs/GIT_WORKFLOW.md` (branching, commits, PR checklist) and
`docs/VALIDATION.md` (no mechanics without an independent reference).
`STATUS.md` is the living hand-over document: read first, update last.

## Disclaimer

IBRT_CCE is a research and learning platform. Results are **not**
design-approved and do not replace the responsibility of a qualified
structural engineer or checks required by building codes.
